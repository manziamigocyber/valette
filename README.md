# AUK

Custom luxury bags storefront built with React + Vite.

**Brand:** AUK — *We Make It Happen* · *As u know!*

Handcrafted luxury bags from Kigali, Rwanda.

## Features

- Product collection showcase
- Craftsmanship & atelier sections
- Contact / custom design inquiry form

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- [React](https://react.dev)
- [Vite](https://vite.dev)
